## 1. Purpose

This corpus is the regression benchmark for every clinical layer of
HairOS. A release is gated on its score against this corpus — see
[HAIROS_RELEASE_GATE_SPEC.md](./HAIROS_RELEASE_GATE_SPEC.md).

The corpus exercises:

- Questionnaire Engine — answer → signal extraction
- Signal Registry — confidence, conflict, dedup
- Pathway Engine — activation graph
- Root Cause Engine — Bayesian posterior, dissent, multifactorial gate
- Protocol Engine — kit selection, gating rules
- Monitoring Engine — labs / scope schedule
- Narrative Engine — themes, doctor/patient/scientific framings

The corpus is **deterministic**: identical inputs produce identical
expected outputs. Reruns are reproducible across machines.

## 2. Distribution (n = 200)

| Category                 | n  | Range covered                       |
|--------------------------|----|-------------------------------------|
| Male AGA                 | 50 | Norwood 1→7, ages 18–72             |
| FPHL                     | 25 | Ludwig 1→3, peri / post-menopause   |
| PCOS-associated          | 25 | classic, lean, normo-androgen, post-bariatric |
| Acute Telogen Effluvium  | 20 | post-fever, postpartum, crash diet, surgical, drug-induced |
| Chronic Telogen Effluvium| 20 | chronic stress, chronic illness, idiopathic |
| Post-illness / Post-COVID| 10 | acute + late post-COVID phenotypes  |
| Alopecia Areata          | 15 | patchy, ophiasis, totalis trajectory, alopecia-areata-history relapse |
| Inflammatory scalp       | 15 | seborrheic, psoriatic, folliculitis decalvans |
| Multifactorial mixed     | 20 | AGA+TE, AGA+inflammation, PCOS+TE, AGA+PCOS+nutritional |

Each category contains a mix of severity bands (mild / moderate / severe)
and presentation clarities (clear / ambiguous / conflicting / edge_case).

**Adversarial cases:** at minimum 50 cases across categories carry
`adversarial.isAdversarial = true`. The adversarial set covers — without
duplication of the underlying clinical class:

- AGA + ferritin deficiency
- AGA + severe scalp inflammation
- PCOS without obesity
- PCOS with normal androgen profile
- TE mimicking AGA (chronic diffuse with crown emphasis)
- AA mimicking TE (incipient diffuse AA)
- Inflammation masking AGA (oily, dandruff-with-itching covering
  miniaturization)
- Multifactorial overlap requiring `compositeRule` activation

## 3. Case authoring rules

1. Every case MUST validate against `ClinicalReplayCase` in the schema.
2. Every `expectedSignals.signalId` MUST exist in
   `src/packages/registries/signals/registry.json`.
3. Every `expectedPathways.pathwayId` MUST exist in
   `src/packages/registries/pathways/registry.json`.
4. Every `expectedRootCauses.causeId` and `expectedDiagnosis.primary`
   MUST exist in `src/packages/registries/causes/registry.json`.
5. `expectedDiagnosis.legacyDiagnosisKey` MUST appear in the
   `legacyMappings` block of the corresponding cause OR in the
   `legacyDiagnosisKeysNotMappedToCauses` (non-cause routing) list.
6. `clinicalRationale.whyPrimary` MUST be ≥ 50 words.
7. `clinicalRationale.whyNotCompetitors` MUST address every cause whose
   prior + signal evidence in this case exceeds 0.05 posterior.
8. Cases MUST NOT contain free-text questionnaire answers that bypass
   the option set — they go through the same extraction the runtime
   uses.

---

## 4. Versioning

- Adding new cases: minor bump (2.0.0 → 2.1.0). Existing cases unchanged.
- Modifying expected outputs of an existing case: major bump
  (2.0.0 → 3.0.0). Requires release-gate re-baselining.
- Removing cases: forbidden. Mark `deprecated: true` (extension under
  `extended.deprecated`) and exclude from gating but keep on disk.
