Sheet: How To Use

How To Use — Dr. FACT Sequential Protocol Designer |  |
ACTION | INSTRUCTION | EXAMPLE / NOTE
Step 1 | Open the "Sequential Protocol Designer" sheet | First tab in this workbook
Step 2 | Find the row matching your patient condition | e.g. "PCOS — Hair Loss only (No obesity)"
Step 3 | Phase 1 column = the FIRST kit (Month 1-2). This MUST repair the cellular terrain. | e.g. F-PCOS -1
Step 4 | Phase 2 column = second kit (Month 3-4). Targets primary hair condition. | e.g. PHENOTYPE INFLAMATION
Step 5 | Phase 3 (Month 5-6) — only if a hormonal/metabolic layer is needed | e.g. PRO IMMUNE GOLD
Step 6 | Phase 4 (Month 7-8) — only for severe/multi-factorial cases | Leave blank if not needed
Step 7 | Update "Total Phases" column with 1, 2, 3 or 4 | Tells the AI how long the protocol is
Step 8 | Update "Clinical Rationale" column with your reasoning | The AI will use this to explain to patients
Step 9 | Add a NEW ROW at the bottom if you need a new condition not listed | Use exact kit names from Kit Master Reference sheet
|  |
CLINICAL RULE | PRINCIPLE | WHY
Phase 1 always | Repair the cellular ENVIRONMENT first | Inflamed / deficient cells cannot respond to targeted treatment
Phase 2 | Target the PRIMARY hair condition | Cellular terrain is now ready — kit absorbs and works
Phase 3 | Address HORMONAL or METABOLIC layer | Systemic correction that sustains Phase 2 results
Phase 4 | CONSOLIDATE — prevent relapse | Immune modulation prevents regression in severe cases
|  |
Kit naming | Always use EXACT kit names as in "Kit Master Reference" sheet | Prevents AI mapping errors
Veg patients | Write base kit name — AI auto-switches to VEG variant | Write HAIR FACT TE GOLD, not TE GOLD VEG
Multi-factorial | PHENOTYPE INFLAMATION should almost always be Phase 1 or 2 | It clears the terrain that blocks every other kit
